# Слушать всем

Android-приложение для прослушивания аудиокниг с поддержкой нескольких источников, Android TV, планшетов и облачной синхронизации.

## Возможности

- **Воспроизведение аудиокниг** — потоковое воспроизведение по главам, скорость воспроизведения, таймер сна, закладки.
- **Множество источников** — десятки библиотек аудиокниг (IziBuk, Knigavuhe, Aume, Akniga, BazaKnig, Knigoblud и др.) в отдельных модулях.
- **Загрузки** — скачивание книг в личную папку приложения или выбранную папку, управление загрузками.
- **Плейлист / главы** — список глав с быстрым переключением, показ/скрытие плейлиста в ТВ-плеере.
- **Android TV** — специальный интерфейс с боковой навигацией, обводкой фокуса и ТВ-плеером.
- **Планшет** — в альбомной ориентации используется ТВ-интерфейс, в портретной — интерфейс смартфона.
- **Разделы** — Главная, Жанры, История, Загрузки, Я (Избранное, Буду слушать, Настройки).
- **Облачная синхронизация** — Google-синхронизация через Firebase (закладки, история, избранное).
- **Настройки** — тема, акцентный цвет, масштаб шрифта, выбор режима управления.
- **Обновления** — проверка и установка обновлений приложения.
- **Смена иконки** — переключение иконок приложения.

## Технологии

- **Kotlin**, **Jetpack Compose** (Material 3)
- **Coil** — загрузка обложек
- **Firebase** — облачная синхронизация
- **Torrent** — потоковое воспроизведение
- Многомодульная структура (Gradle)

## Модули

- `app` — основной модуль приложения
- `source-api` — API источников аудиокниг
- `source-izibuk` — источник IziBuk
- `source-extra` — дополнительные источники
- `storagechooser` — выбор папки хранения

## Сборка

Требуется JDK 17+ и Android SDK.

```bash
./gradlew :app:assembleRelease
```

APK создаётся в `app/build/outputs/apk/release/`.

## Требования

- Android 7.0 (API 24) и выше.
- Для синхронизации требуется настроенный Firebase-проект.
